# Нефтянка

Проект платформы для консолидации и визуализации инженерных данных ООО «Недра».

Платформа должна объединять данные из разных источников и помогать сотрудникам работать с ними в одном месте.

## Текущий этап

Сейчас команда уточняет план проекта и состав первой версии (MVP). В работе:

- описание предметной области и бизнес-процессов;
- диаграммы процессов, список функций и пользовательские сценарии;
- модели данных;
- подготовка инфраструктуры.

Технологический стек ещё не утверждён. Репозиторий создан для дальнейшей разработки; инструкции по запуску появятся вместе с кодом.
